# MNE-Course

This repository contains the lesson materials for a multi-day MNE-Python course.

Required python packages:
- `mne-python`
- `sphinx`
- `sphinx_copybutton`

To build the materials:
```
sphinx-build -b html . ./html
```

Accompanying data package (4.3GB): [download link](https://drive.google.com/file/d/1UyLeX6VLKrCf02TzkWEbTa8kuwo5evgP/view?usp=sharing)
