# MNE-Course

You can find the HTML version at: https://users.aalto.fi/~vanvlm1/mne-course

This repository contains the lesson materials for a multi-day MNE-Python course.

Required python packages:
- `mne-python`
- `sphinx`
- `sphinx_copybutton`

To build the materials:
```
sphinx-build -b html . ./html
```

Accompanying data package (1.6GB): [download link](https://drive.google.com/file/d/1UyLeX6VLKrCf02TzkWEbTa8kuwo5evgP/view?usp=sharing)
